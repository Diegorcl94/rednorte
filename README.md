# RedNorte Fullstack

Plataforma inteligente para la gestión de listas de espera hospitalarias del Servicio Público de Salud RedNorte.

## Arquitectura del sistema

El sistema estará basado en una arquitectura de microservicios, compuesta por:

- Frontend React
- Backend For Frontend BFF
- Microservicio de pacientes y usuarios
- Microservicio de listas de espera
- Microservicio de reasignación automática de horas médicas
- Base de datos MySQL
- Documentación Swagger / OpenAPI

## Tecnologías

- React + Vite
- Java Spring Boot
- Maven
- Spring Data JPA
- Spring Security + JWT
- MySQL
- Swagger
- GitHub
